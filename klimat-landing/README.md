# КліматМонтаж: лендінг на Next.js

Одно сторінковий сайт для послуги монтажу кондиціонерів. Next.js (App Router), TypeScript, Tailwind CSS v4.

## Запуск

Потрібен Node.js 20 або новіший.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Відкрий http://localhost:3000.

## Що змінити перед запуском

Усе потрібне зібрано в `lib/config.ts`:

- назва, місто, телефон, Telegram, Viber, графік роботи
- **ціни**: зараз це приклад, постав свої
- етапи, переваги, питання й відповіді
- **відгуки**: масив `REVIEWS` порожній, секція з'явиться, коли додаси справжні відгуки

Також заміни `example.com` у `.env.local` (`NEXT_PUBLIC_SITE_URL`) на свій домен.

## Заявки з форми

Форма надсилає дані на `app/api/lead/route.ts`, а той пересилає їх у Telegram.

1. Створи бота в @BotFather, скопіюй токен.
2. Напиши боту повідомлення, відкрий `https://api.telegram.org/bot<TOKEN>/getUpdates` і знайди `chat.id`.
3. Впиши обидва значення в `.env.local` (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).

Без цих змінних заявки просто виводяться в консоль, тож локально все працює.
